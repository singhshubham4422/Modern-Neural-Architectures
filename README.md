## 📌 Transformer (Modular Implementation)

A modular implementation of the Transformer from *“Attention Is All You Need”*, focused on clean abstraction and scalability.

## 🛠 Features
- Modular Attention, FFN, LayerNorm  
- Encoder–Decoder architecture  
- Positional Encoding  
- Training pipeline  

## 📂 Structure  
- `Report.pdf` – explanation  
- `notebook.ipynb` – experiments  
- `Tiny Shakespeare dataset.zip` – dataset
